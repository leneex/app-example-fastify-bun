# Fastify on Bun

Example [Fastify](https://fastify.dev/) app running on [Bun](https://bun.sh/). Fastify is a fast, low-overhead web framework for Node.js. Bun is a fast all-in-one JavaScript runtime and package manager compatible with Node.js.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `3000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
bun install

# start the app
bun run start
```
